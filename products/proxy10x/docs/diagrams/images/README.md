# Diagram Images

This folder contains PNG exports of the Draw.io diagrams for use in the README and documentation.

## Files

- `proxy10x-architecture.png` - Platform architecture overview
- `cicd-pipeline.png` - CI/CD pipeline with Ansible & Kubernetes
- `helm-deployment-scaling.png` - Kubernetes Helm deployment and auto-scaling
- `request-flow.png` - Request processing flow through Proxy10x

## How to Generate

1. Open the corresponding `.drawio` file in [draw.io](https://app.diagrams.net/)
2. Go to **File → Export as → PNG**
3. Set **Border Width** to 10
4. Set **Scale** to 200% for high resolution
5. Enable **Transparent Background** (optional)
6. Click **Export** and save to this folder

## Usage in README

```markdown
![Proxy10x Architecture](docs/diagrams/images/proxy10x-architecture.png)
```
