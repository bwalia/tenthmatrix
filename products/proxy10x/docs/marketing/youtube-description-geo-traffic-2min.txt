Proxy10x Geographic Traffic Distribution — see who hits your edge, by country (2 min)

Live Top Countries list + world map on the admin dashboard. Every request is
tagged with a country from IP2Location on the OpenResty hot path, aggregated in
shared-dict traffic stats, and painted on the choropleth — so you know where
traffic (and abuse) is coming from without leaving the control plane.

HOW IT WORKS (ENGINEERING)
────────────────────────────────────────
• Per-request country lookup via IP2Location (settings.ip2location_path /
  ansible install path under OpenResty)
• $geo_country for access logs; log_handler aggregates into traffic_stats
• Admin UI GeoTrafficMap (React Admin + Next.js) colors countries by request volume
• ISO normalization: IP2Location “UK” → “GB” for atlas matching
• Prometheus /metrics still exports edge golden signals for Grafana
  (job=proxy10x-edges) — complementary to the in-product geo panel
